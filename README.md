# Unicode Type

Утилита на Python (Tkinter) для посимвольного ввода Unicode-текста в другие окна без переключения раскладки клавиатуры.

## Быстрый старт

1. Скачайте проект и убедитесь, что установлен **Python 3.11+** (с поддержкой **Tkinter**).
2. Запустите скрипт:
   - **Windows:** `python windows.py` *(запускайте от имени Администратора, если целевое окно требует прав)*.
   - **macOS:** установите `pip install pyobjc-framework-Quartz` и запустите `python3 macos.py`. Обязательно выдайте IDE/Terminal права **Универсального доступа (Accessibility)** в системных настройках.

## Горячие клавиши

Глобальные хоткеи работают в фоне, из любого окна:

| Действие | macOS | Windows |
| :--- | :--- | :--- |
| **Скопировать выделенный текст в программу** | `Ctrl + C` | `Alt + C` |
| **Начать печать текста** | `Ctrl + V` | `Alt + V` |
| **Остановить печать** | `Ctrl + B` | `Alt + B` |
