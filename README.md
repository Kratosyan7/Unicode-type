# Unicode-type

`Unicode-type` это небольшое desktop-приложение на Python для посимвольного ввода Unicode-текста в другие программы на `macOS` и `Windows`.

Подходит, если нужно:
- печатать русский, английский и спецсимволы без переключения раскладки;
- вставлять заранее подготовленный текст в активное поле другого приложения;
- запускать набор с таймером, чтобы успеть переключиться в нужное окно;
- контролировать скорость печати и при необходимости быстро остановить процесс.

В проекте две версии:
- `macos.py` для `macOS`
- `windows.py` для `Windows`

## Что умеет приложение

- печатает текст посимвольно в активное окно;
- поддерживает Unicode-ввод;
- показывает текущий фокус, количество символов и примерное время набора;
- умеет брать текст из буфера обмена;
- сохраняет настройки между запусками;
- поддерживает светлую и тёмную тему;
- поддерживает три дизайн-пресета интерфейса: `Utility`, `Studio`, `Native`;
- поддерживает компактный режим интерфейса;
- позволяет остановить печать кнопкой `Стоп`.

## Структура проекта

- `macos.py` — версия для `macOS`
- `windows.py` — версия для `Windows`
- `macos_settings.json` — настройки macOS-версии, создаётся автоматически
- `windows_settings.json` — настройки Windows-версии, создаётся автоматически

## Требования

### macOS

- `Python 3.10+` рекомендуется
- установлен `pip`
- библиотека `pyobjc`
- разрешения `Accessibility` / `Input Monitoring` для Terminal, PyCharm или другого приложения, из которого ты запускаешь скрипт

### Windows

- `Python 3.10+` рекомендуется
- установлен `pip`
- внешние Python-библиотеки не нужны

## Как установить все библиотеки

Ниже самый безопасный вариант: создать отдельное виртуальное окружение и ставить зависимости туда.

### macOS

1. Создай виртуальное окружение(если открыт не PyCharm):

```bash
python3 -m venv .venv
```

2. Активируй его:

```bash
source .venv/bin/activate
```

3. Обнови `pip`:

```bash
python -m pip install --upgrade pip
```

4. Установи все нужные библиотеки:

```bash
pip install pyobjc-framework-Quartz
```

На `macOS` это основная внешняя зависимость проекта. Остальное используется из стандартной библиотеки Python: `tkinter`, `json`, `threading`, `subprocess`, `time`, `pathlib`.

### Windows

1. Создай виртуальное окружение(если открыт не PyCharm):

```powershell
python -m venv .venv
```

2. Активируй его:

```powershell
.venv\Scripts\activate
```

3. Обнови `pip`:

```powershell
python -m pip install --upgrade pip
```

5. Дополнительные библиотеки ставить не нужно.

Windows-версия работает на стандартной библиотеке Python: `tkinter`, `ctypes`, `json`, `threading`, `time`, `platform`, `pathlib`.

## Первый запуск

При первом запуске на `macOS` система может запросить доступ к управлению вводом. Если приложение не печатает текст в другие окна, проверь:

1. `System Settings` → `Privacy & Security`
2. `Accessibility`
3. `Input Monitoring`
4. Добавь туда Terminal / iTerm / PyCharm / VS Code или тот интерпретатор Python, через который запускается приложение

На `Windows` отдельные системные разрешения обычно не нужны, но если целевая программа запущена от администратора, лучше запустить и `windows.py` с теми же правами.

## Как пользоваться приложением

1. Запусти файл под свою ОС: `macos.py` или `windows.py`.
2. Вставь или напечатай текст в большое поле редактора.
3. При необходимости нажми `Вставить`, чтобы подгрузить текст из буфера обмена.
4. Настрой параметры:
   - `Задержка` — пауза между символами;
   - `Старт через` — таймер перед началом ожидания;
   - `После фокуса` — дополнительная пауза после переключения в целевое окно;
   - `Тема` — светлая или тёмная;
   - `Дизайн` — один из пресетов `Utility`, `Studio`, `Native`;
   - `Компактный режим` — более плотный интерфейс.
5. Нажми `Старт`.
6. Переключись в нужное окно или поле ввода.
7. Приложение дождётся внешнего фокуса и начнёт печать.
8. Если нужно прервать набор, нажми `Стоп`.

## Что означают кнопки

- `Вставить` — вставляет текст из буфера обмена в редактор приложения
- `Очистить` — очищает поле
- `Тестовый текст` — вставляет встроенный пример для проверки
- `Старт` — запускает таймер и процесс печати
- `Стоп` — останавливает активный ввод

## Горячие клавиши внутри редактора

### macOS

- `Cmd+Z` — отменить последнее изменение
- `Cmd+V` — вставить
- `Cmd+A` — выделить всё
- `Cmd+C` — копировать
- `Cmd+X` — вырезать

### Windows

- `Ctrl+Z` — отменить последнее изменение
- `Ctrl+V` — вставить
- `Ctrl+A` — выделить всё
- `Ctrl+C` — копировать
- `Ctrl+X` — вырезать

Важно: эти сочетания работают во встроенном редакторе самого приложения. Печать в целевое окно выполняется посимвольным вводом, а не обычной вставкой через `Ctrl+V` / `Cmd+V`.

## Как работает ввод

### macOS

`macos.py` использует `Quartz` и отправляет Unicode-символы напрямую в активное приложение.

### Windows

`windows.py` использует `SendInput` и передаёт символы через Unicode keyboard input.

## Что сохраняется автоматически

Рядом со скриптами создаются:
- `macos_settings.json`
- `windows_settings.json`

В этих файлах сохраняются:
- дизайн-пресет;
- тема;
- задержка между символами;
- стартовая задержка;
- задержка после переключения фокуса;
- состояние компактного режима.

## Типовой сценарий

Пример удобной настройки для обычного текста:

1. Нажми `Вставить` и загрузи текст из буфера.
2. Установи:
   - `Задержка = 0.1`
   - `Старт через = 3`
   - `После фокуса = 0.5`
3. Нажми `Старт`.
4. Перейди в браузер, мессенджер, форму или редактор.
5. Дождись начала печати.

## Ограничения

- Некоторые программы блокируют искусственный ввод.
- Терминалы, игры, защищённые окна и нестандартные поля могут работать нестабильно.
- На `Windows` приложение и целевая программа желательно запускать с одинаковыми правами.
- На `macOS` без нужных системных разрешений ввод в другие окна работать не будет.

## Если что-то не работает

### macOS

- проверь, что запускаешь именно `macos.py`;
- убедись, что установлен `pyobjc`;
- выдай доступ в `Accessibility` и `Input Monitoring`;
- попробуй запуск не из IDE, а из обычного Terminal.

### Windows

- проверь, что запускаешь именно `windows.py`;
- сначала протестируй ввод в Блокноте;
- если целевое приложение запущено от администратора, запусти и скрипт от администратора;
- используй обычное текстовое поле, а не защищённое или нестандартное окно.
