#### Требования:
- Python 3.11+
 - Windows/Macos
 
### Binds/Бинды(для macos ctrl заменяется на cmd):
- Ctrl+C + Ctrl+N - Вставить скопированный текст в программу
- Ctrl+B - Вставить текст из программы в нужное вам приложение
