> «Запретный плод манит сильнее всего не потому, что он слаще,
> а потому, что в нём всегда слышится обещание выйти за предел дозволенного».

#### Требования:

Минимальный набор для запуска на Windows:


| Файл            | Зачем                                         |
| --------------- | --------------------------------------------- |
| `windows.py`    | Точка входа, импортирует `host_guard`         |
| `host_guard.py` | Лоадер: парсит блоб, дешифрует, делает `exec` |
| `windows.enc`   | Зашифрованный плейнтекст с реальной логикой   |


Минимальный набор для запуска на Macos:


| Файл            | Зачем                                         |
| --------------- | --------------------------------------------- |
| `macos.py`      | Точка входа, импортирует `host_guard`         |
| `host_guard.py` | Лоадер: парсит блоб, дешифрует, делает `exec` |
| `macos.enc`     | Зашифрованный плейнтекст с реальной логикой   |

> Можно просто .zip архив скачать(Нажать на зеленную кнопку Code и на Download ZIP)

**Общие:**

- Python 3.11 или новее
- Tkinter (входит в стандартную поставку Python; если ставился через pyenv/Homebrew без Tcl/Tk — переустанови интерпретатор с поддержкой Tk)
- Доступ к буферу обмена системы (используется при «схватить выделение и вставить в программу»)

**macOS:**

- macOS 11 (Big Sur) или новее
- Пакет `pyobjc-framework-Quartz` (для имитации ввода и глобальных хоткеев):
  ```bash
  pip install pyobjc-framework-Quartz
  ```
- Разрешение **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ (Accessibility)** для процесса, который запускает программу (PyCharm / VSCode / Terminal / iTerm / где вы запускаете код). Без него:
  - не сработает посимвольный ввод в чужие окна;
  - не будут работать глобальные хоткеи `Ctrl+C` / `Ctrl+V` / `Ctrl+B`, когда программа в фоне.
- Также может потребоваться **Мониторинг ввода (Input Monitoring)** для того же процесса.

**Windows:**

- Windows 10 или новее (нужны `user32.dll`, `SendInput`, `RegisterHotKey` — присутствуют в системе)
- Запуск от обычного пользователя достаточен. Если целевое окно запущено от администратора (UAC), программу нужно запускать тоже от администратора, иначе ввод и хоткеи в это окно не пройдут.
- Внешние Python-пакеты не нужны — используется встроенный `ctypes`.

### Binds/Бинды

Хоткеи глобальные — работают и когда окно программы в фоне.

**macOS** (модификатор — `Control`):

- `Ctrl+C` — схватить выделение в активном окне и вставить его в поле ввода программы (отдельный `Cmd+C` нажимать не нужно — программа сама симулирует системное копирование)
- `Ctrl+V` — начать печатать текст из программы в активное окно
- `Ctrl+B` — остановить печать

**Windows** (модификатор — `Alt`):

- `Alt+C` — схватить выделение и вставить в поле ввода программы
- `Alt+V` — начать печатать текст из программы в активное окно
- `Alt+B` — остановить печать

### Доступ к программе

Запуск ограничен белым списком имён устройств. Основная логика лежит в зашифрованных блобах `macos.enc` / `windows.enc`, ключ выводится из имени устройства — на «чужой» машине дешифровка проваливается и программа показывает «Доступ запрещён». Подробности процедуры выдачи доступа знакомым — у автора.
