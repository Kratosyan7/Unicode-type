# Unicode-type

Приложение для посимвольного ввода Unicode-текста в другие программы на `macOS` и `Windows`.

Подходит для случаев, когда нужно:
- печатать русский и английский текст в одной строке;
- не зависеть от раскладки при наборе;
- вставлять текст в поле редактора через горячие клавиши;
- запускать печать с задержкой после переключения в нужное окно.

В проекте две версии:
- `macos.py` для `macOS`
- `windows.py` для `Windows`

## Возможности

- светлая и тёмная темы;
- компактный режим интерфейса;
- сохранение настроек между запусками;
- счётчик символов и примерное время набора;
- отдельная задержка перед стартом и дополнительная задержка после смены фокуса;
- вставка текста из буфера в поле редактора;
- горячие клавиши под английскую и русскую раскладку для редактора;
- безопасная остановка процесса кнопкой `Стоп`.

## Что сохраняется

Настройки автоматически сохраняются рядом со скриптами:
- `macos_settings.json`
- `windows_settings.json`

Сохраняются:
- тема;
- задержка между символами;
- стартовая задержка;
- задержка после переключения фокуса;
- состояние компактного режима.

## Требования

### macOS

- Python 3
- модуль `pyobjc` с доступом к `Quartz`
- разрешение на управление вводом для Terminal / PyCharm / Python, если macOS его запросит

### Windows

- Python 3
- дополнительных библиотек не требуется

## Запуск

### macOS

```bash
python3 macos.py
```

Если не хватает модулей Quartz/AppKit:

```bash
pip install pyobjc
```

### Windows

```bash
python windows.py
```

## Как пользоваться

1. Запусти нужный файл под свою ОС.
2. Вставь или введи текст в большое поле редактора.
3. При необходимости настрой:
   - `Задержка` — интервал между символами;
   - `Старт через` — сколько ждать после нажатия `Старт`;
   - `После фокуса` — дополнительная пауза после того, как ты переключишься в целевое окно;
   - `Тема`;
   - `Компактный режим`.
4. Нажми `Старт`.
5. Переключись в нужное окно или поле ввода.
6. Приложение дождётся внешнего фокуса, выдержит задержку `После фокуса` и начнёт печать.
7. Если нужно остановить ввод, нажми `Стоп`.

## Кнопки

- `Вставить` — вставляет текст из буфера обмена в редактор приложения
- `Очистить` — очищает поле
- `Тестовый текст` — вставляет пример
- `Старт` — запускает ожидание и печать
- `Стоп` — останавливает процесс

## Горячие клавиши внутри редактора

### macOS

- `Cmd+V` или `Cmd+М` — вставить
- `Cmd+A` или `Cmd+Ф` — выделить всё
- `Cmd+C` или `Cmd+С` — копировать
- `Cmd+X` или `Cmd+Ч` — вырезать

### Windows

- `Ctrl+V` или `Ctrl+М` — вставить
- `Ctrl+A` или `Ctrl+Ф` — выделить всё
- `Ctrl+C` или `Ctrl+С` — копировать
- `Ctrl+X` или `Ctrl+Ч` — вырезать

Примечание: эти сочетания относятся к встроенному полю редактора самого приложения. Печать в целевое окно выполняется не вставкой, а посимвольным вводом.

## Как работает печать

### macOS

`macos.py` использует `Quartz` и отправляет Unicode-символы напрямую в активное приложение.

### Windows

`windows.py` использует `SendInput` и посылает символы через Unicode keyboard input.

## Ограничения

- Некоторые приложения могут блокировать искусственный ввод.
- Терминалы, игры, защищённые окна, админские окна и нестандартные поля могут работать нестабильно или не принимать ввод.
- На Windows целевое приложение и этот скрипт желательно запускать с одинаковыми правами.
- На macOS может понадобиться выдать права на Accessibility / Input Monitoring в системных настройках.

## Типовой сценарий

1. Открой приложение.
2. Нажми `Вставить` и подгрузи текст из буфера.
3. Установи:
   - `Задержка = 0.1`
   - `Старт через = 3`
   - `После фокуса = 0.5`
4. Нажми `Старт`.
5. Перейди в нужное поле в браузере, мессенджере или редакторе.
6. Дождись старта печати.

## Структура проекта

- `macos.py` — версия для macOS
- `windows.py` — версия для Windows
- `macos_settings.json` — настройки macOS-версии, создаётся автоматически

## Если что-то не работает

### На macOS

- проверь, что запускаешь именно `macos.py`;
- проверь права доступа для Python / терминала / IDE;
- попробуй запуск не из IDE, а из Terminal.

### На Windows

- проверь, что запускаешь именно `windows.py`;
- попробуй обычное поле в Блокноте;
- если целевое приложение запущено от администратора, запусти и скрипт от администратора.
