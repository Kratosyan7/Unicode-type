> «Запретный плод манит сильнее всего не потому, что он слаще,
> а потому, что в нём всегда слышится обещание выйти за предел дозволенного».

`Unicode-type` это небольшое desktop-приложение на Python для посимвольного ввода Unicode-текста в другие программы на `macOS` и `Windows`. К нему прилагается отдельный движок автоматизации, который умеет проигрывать готовые сценарии (клики + печать) или подсовывать тексты в буфер обмена один за другим.

Подходит, если нужно:

- печатать русский, английский и спецсимволы без переключения раскладки;
- вставлять заранее подготовленный текст в активное поле другого приложения;
- запускать набор с таймером, чтобы успеть переключиться в нужное окно;
- автоматически заполнить большую форму из готового набора данных;
- по горячей клавише пролистывать заготовленные блоки текста через буфер обмена.

## Что внутри проекта

Две связанные пары приложений и пресет под одну конкретную форму.

### Базовая печать (Unicode Text Typer)

Простое окно с текстовым редактором. Вставляешь или печатаешь текст, нажимаешь `Старт`, переключаешься в целевое окно — программа печатает посимвольно.

- `macos.py` — версия для `macOS`
- `windows.py` — версия для `Windows`

### Автоматизация (Unicode Auto Typer)

Окно с двумя вкладками: «Автомат» (проигрывает JSON-сценарий с кликами и печатью) и «Помощник» (кладёт тексты в буфер обмена один за другим).

- `macos-auto.py` — версия для `macOS`
- `windows-auto.py` — версия для `Windows`

### Пресет КВ_1 (АРМ Студента)

Готовые данные курсовой работы и генератор сценария под форму «Дерево иерархии объектов».

- `kv1/data.json` — структурированный отчёт (объекты, функции, инструменты)
- `kv1/make_scenario.py` — CLI-генератор сценария
- `kv1/profile.json` — профиль координат после калибровки (создаётся вручную или скриптом)
- `kv1/scenario.json` — готовый сценарий для проигрывания (создаётся генератором)

## Требования

### macOS

- `Python 3.10+` рекомендуется
- установлен `pip`
- библиотека `pyobjc-framework-Quartz` (для печати и клика)
- разрешения `Accessibility` для Terminal, PyCharm или другого приложения, из которого ты запускаешь скрипт. Без них не работает ни печать в чужие окна, ни глобальные горячие клавиши.

### Windows

- `Python 3.10+` рекомендуется
- установлен `pip`
- внешние Python-библиотеки не нужны (`ctypes` идёт со стандартной библиотекой)

## Как пользоваться базовой печатью

1. Запусти файл под свою ОС.
2. Вставь или напечатай текст в большое поле редактора.
3. При необходимости нажми `Вставить`, чтобы подгрузить текст из буфера обмена.
4. Настрой параметры:
   - `Задержка` — пауза между символами;
   - `Старт через` — таймер до начала ожидания;
   - `После фокуса` — дополнительная пауза после переключения в целевое окно;
   - `Тема` — светлая или тёмная;
   - `Дизайн` — один из пресетов `Utility`, `Studio`, `Native`;
   - `Компактный режим` — более плотный интерфейс.
5. Нажми `Старт`.
6. Переключись в нужное окно или поле ввода.
7. Приложение дождётся внешнего фокуса и начнёт печать.
8. Если нужно прервать набор, нажми `Стоп`.

### Что означают кнопки

- `Вставить` — вставляет текст из буфера обмена в редактор приложения
- `Очистить` — очищает поле
- `Старт` — запускает таймер и процесс печати
- `Стоп` — останавливает активный ввод

### Горячие клавиши редактора (macOS)

- `Cmd+Z` — отменить последнее изменение
- `Cmd+V` — вставить
- `Cmd+A` — выделить всё
- `Cmd+C` — копировать
- `Cmd+X` — вырезать

### Горячие клавиши редактора (Windows)

- `Ctrl+Z` — отменить последнее изменение
- `Ctrl+V` — вставить
- `Ctrl+A` — выделить всё
- `Ctrl+C` — копировать
- `Ctrl+X` — вырезать

Эти сочетания работают только во встроенном редакторе. Печать в целевое окно идёт посимвольным вводом, а не обычной вставкой.

## Автоматизация

`macos-auto.py` и `windows-auto.py` — отдельные приложения с двумя вкладками.

### Вкладка «Автомат»

Проигрывает JSON-сценарий с кликами и печатью.

#### Шаги работы (Автомат)

1. Создай новый сценарий кнопкой `Новый` или открой готовый кнопкой `Открыть`.
2. Откалибруй точки экрана:
   - нажми `Калибровать поле`,
   - введи имя поля (например `func_row1_name`),
   - наведи курсор на нужное место в целевом окне,
   - либо подожди 3 секунды, либо нажми `F8` — координата запишется мгновенно.
3. Если у тебя есть готовый `data.json`, нажми `Сгенерировать из data.json...` — программа сама построит шаги по откалиброванным точкам.
4. При необходимости поправь шаги вручную в текстовом блоке (это обычный JSON).
5. Нажми `Сохранить`. Файл сценария — единый JSON, путь сохраняется как абсолютный.
6. Параметры:
   - `Старт через, сек` — пауза до начала проигрывания (успей переключиться в целевое окно);
   - `Между шагами, сек` — задержка между действиями;
   - `Между символами, сек` — задержка между Unicode-символами при печати.
7. Нажми `Старт`. Чтобы прервать — `Стоп`.

#### Поддерживаемые действия

```json
[
  {"action": "click", "field": "имя_калиброванного_поля"},
  {"action": "click", "x": 950, "y": 514},
  {"action": "type",  "text": "Привет, мир!"},
  {"action": "key",   "name": "tab"},
  {"action": "sleep", "seconds": 0.5}
]
```

`action: key` принимает `tab`, `return`/`enter`, `esc`, `space`, `backspace`, `delete`, `up`, `down`, `left`, `right`.

#### Формат сценария целиком

```json
{
  "fields": {
    "func_row1_name": [950, 514],
    "func_row2_name": [950, 544]
  },
  "steps": [
    {"action": "click", "field": "func_row1_name"},
    {"action": "type",  "text": "set_object_name"},
    {"action": "key",   "name": "tab"},
    {"action": "type",  "text": "изменение имени объекта"}
  ]
}
```

### Вкладка «Помощник»

Идея: программа не управляет курсором — она просто кладёт тексты в системный буфер обмена один за другим. Координаты не нужны вообще.

#### Шаги работы (Помощник)

1. Загрузи блоки одной из двух кнопок:
   - `Загрузить из data.json...` — раскладывает объекты, функции и инструменты в плоский список;
   - `Из текущего сценария` — берёт все шаги `type` из активного сценария вкладки «Автомат».
2. Нажми `Старт помощника` — первый блок попадает в буфер обмена.
3. В целевой форме:
   - `Cmd+V` (macOS) или `Ctrl+V` (Windows) — вставить;
   - `Tab` — следующее поле формы;
   - `F9` или кнопка `Следующий` — пролистать на следующий блок.
4. Двойной клик по блоку в списке — переключиться на конкретный блок (если хочешь пропустить или вернуться).
5. `Стоп` — выключить помощника.

В отличие от автомата, окно целевой программы можно двигать как угодно — координаты не используются.

### Глобальные горячие клавиши

- `F8` — записать текущую позицию курсора в активное калибрующееся поле.
- `F9` — следующий блок в режиме «Помощник».

#### macOS (CGEventTap)

Глобальный мониторинг событий клавиатуры идёт через `CGEventTap` в отдельном run-loop потоке. Нужны разрешения `Accessibility`. Если разрешений нет — индикатор в нижнем правом углу окна это сообщит, и горячие клавиши работать не будут (но кнопки в окне продолжат работать).

#### Windows (RegisterHotKey)

Глобальные хоткеи регистрируются через `RegisterHotKey` + `GetMessageW`. Если другая программа уже занимает `F8` или `F9`, регистрация не пройдёт — индикатор в окне это покажет, и хоткеи будут работать только когда auto-typer в фокусе.

## Пресет КВ_1 (Дерево иерархии объектов)

Готовый набор данных под курсовую работу с формой АРМ Студента.

### Что внутри `kv1/`

- `data.json` — содержание отчёта в трёх блоках: объекты, функции, инструменты.
- `make_scenario.py` — CLI-скрипт: профиль координат + данные → готовый сценарий.
- `profile.json` — профиль с координатами полей формы (создаётся при первом запуске генератора).
- `scenario.json` — готовый сценарий, который проигрывает auto-typer.

### Имена полей в профиле

Чтобы генератор сработал, нужно откалибровать минимум следующие точки в форме:

- `obj_row1_name` — поле «Наименование» в первой строке таблицы «Используемые объекты»
- `obj_row2_name` — то же во второй строке (нужно только если объектов больше одного)
- `func_row1_name` — поле «Наименование» в первой строке таблицы «Используемые функции»
- `func_row2_name` — то же во второй строке (для расчёта шага между строками)
- `tool_row1_desc` — поле «Описание» в первой строке таблицы «Другие инструменты»
- `tool_row2_desc` — то же во второй строке

Между полями одной строки используется `Tab`, поэтому каждую строку калибровать целиком не нужно. Координаты `row3`, `row4` и далее генератор вычисляет линейной экстраполяцией от `row1` к `row2`.

### Быстрый старт пресета

1. Открой форму АРМ Студента, нажми `+` нужное количество раз, чтобы появились пустые строки в каждой таблице.
2. Запусти `python3 macos-auto.py` (или `windows-auto.py`).
3. Нажми `Открыть`, выбери `kv1/profile.json` (если файла нет — он создастся при следующем шаге).
4. Откалибруй шесть точек кнопками `Калибровать поле` / `Перезаписать` (точку наводишь курсором, жмёшь `F8`).
5. Нажми `Сохранить`.
6. Нажми `Сгенерировать из data.json...` и выбери `kv1/data.json`. В блоке шагов появится около 90 действий.
7. Нажми `Сохранить` ещё раз — теперь сценарий целиком в файле.
8. Нажми `Старт` и в течение 3 секунд переключись в окно АРМ Студента.

### Альтернатива через CLI

Тот же результат можно получить из терминала:

```bash
python3 kv1/make_scenario.py kv1/profile.json kv1/data.json kv1/scenario.json
```

Если `kv1/profile.json` не существует, скрипт создаст пустой шаблон с нужными именами полей и попросит откалибровать его в auto-typer.

## Что сохраняется автоматически

### Настройки базовой печати

`macos_settings.json` / `windows_settings.json`:

- дизайн-пресет;
- тема;
- задержка между символами;
- стартовая задержка;
- задержка после переключения фокуса;
- состояние компактного режима;
- размер и положение окна.

### Настройки автоматизации

`macos_auto_settings.json` / `windows_auto_settings.json`:

- путь последнего открытого сценария;
- задержки (старт, между шагами, между символами).

Сами сценарии, профили координат и `kv1/data.json` лежат там, где ты их сохранил, и в настройках не дублируются.

## Ограничения

- Некоторые программы блокируют искусственный ввод и клики; авто-режим в них не сработает.
- Терминалы, игры и нестандартные защищённые поля могут вести себя непредсказуемо.
- На `Windows` приложение и целевая программа желательно запускать с одинаковыми правами (или оба от администратора).
- На `macOS` без разрешения `Accessibility` ввод и глобальные горячие клавиши работать не будут.
- Координаты в сценарии — абсолютные. Если ты сдвинул целевое окно после калибровки, точки промахиваются. В таком случае используй вкладку «Помощник», там координаты не нужны.

## Если что-то не работает

### Базовая печать на macOS

- проверь, что запускаешь именно `macos.py`;
- убедись, что установлен `pyobjc-framework-Quartz`;
- выдай доступ в `System Settings` → `Privacy & Security` → `Accessibility` тому процессу, из которого запускаешь Python (Terminal, iTerm, PyCharm, VS Code).

### Базовая печать на Windows

- проверь, что запускаешь именно `windows.py`;
- сначала протестируй ввод в Блокноте;
- если целевое приложение запущено от администратора, запусти и скрипт от администратора.

### Автомат промахивается мимо полей

- ты сдвинул целевое окно после калибровки. Перекалибруй или переключись на «Помощник».
- ты запустил auto-typer на дисплее с другим масштабом или Retina-разрешением. Калибровка идёт в логических координатах того дисплея, на котором ты её сделал.
- между шагами слишком маленькая пауза. Подними `Между шагами, сек` до 0.1–0.2.

### Горячие клавиши не срабатывают

- macOS: индикатор в правом нижнем углу пишет «Горячие клавиши недоступны» — выдай Accessibility-доступ в системных настройках и перезапусти.
- Windows: индикатор пишет «Глобальные F8/F9 заняты» — другая программа держит эти клавиши. Закрой её или используй кнопки в окне.
